THE TRINITY — theme music folder
=====================================

Drop your own tracks here as:

  messi.mp3     → La Pulga's hymn (e.g. a soft piano / lo-fi loop)
  ronaldo.mp3   → The Champion's anthem (e.g. calm cinematic ambient)
  neymar.mp3    → Warm tropical lo-fi / soft bossa loop

Then update the `music.url` fields in data/players.ts, e.g.:

  music: { title: "Encara Messi", url: "/audio/messi.mp3", commentary: [...] }

Right now the site streams calm lo-fi beds by Kevin MacLeod
(incompetech.com, CC-BY 4.0 — credited in the site footer) at very low
volume with a smooth fade-in, so there is no sudden blast. Keep any
replacement mellow: the player is designed as a bed, not a club.
Swap in real tracks anytime — the player handles play/pause, mute,
volume and errors.
